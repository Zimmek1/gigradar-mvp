# GigRadar MVP

A simple GitHub Pages-friendly prototype for finding unknown local gigs based on your favorite artists.

## How to use

Open `index.html` in a browser, or upload these files to GitHub and enable GitHub Pages.

## What it does

- Lets users type favorite artists and genres
- Uses sample Facebook/X/Threads-style local show posts
- Pulls band names, venues, genres, and similar artists from sample data
- Scores recommendations based on taste match
- Sorts shows by distance
